# Install Mshanga on your Mac

This is written for people who do not write code.

## Before you begin

You need a Mac with the Codex desktop app and its pet picker. This does not
work as a normal ChatGPT web or phone-app upload.

1. Quit the Codex desktop app.
2. Open **Finder**. From the top menu, choose **Go → Go to Folder…**
   (or press `Shift` + `Command` + `G`).
3. Paste this location and press Return:

   `/Users/mk47/.codex/pets/`

4. Create a new folder called `mshanga` there.
5. Copy this download's `pet.json` and `spritesheet.webp` into the `mshanga`
   folder. Do not rename either file.
6. Reopen Codex. In the pet chooser, select **Mshanga** and start a fresh task.

The packaged sprite is transparent. The bright cyan seen during production was
only a temporary chroma backdrop and is not part of the final asset.

## To uninstall

Remove only `/Users/mk47/.codex/pets/mshanga/`, then restart the app. This
does not affect any other pets.
